# Meheraz Chayan — Project Portfolio

A focused React and TypeScript portfolio for browsing selected projects by category. The catalog includes live search, category filters, project counts, and alphabetical sorting.

## Run locally

```bash
npm install
npm run dev
```

Run `npm run build` to create a production build in `dist/`.

Project content is maintained in `src/data.ts`. The interface is implemented in `src/App.tsx` and `src/styles.css`.
